# tian415

这里放一些自己做的工具和实验，主要和笔记整理、写作有关。开发过程中会用 AI 帮忙，也借这些项目学习怎么把想法做成能运行的东西。

## 做过的几个项目

- [Knowledge Agent](https://github.com/tian415/knowledge-agent)：把 AI 对话整理成 Markdown 笔记，保存前可以查看来源和修改内容。仓库里有不需要 API Key 的演示，可以在本地试用。
- [EchoVault](https://github.com/tian415/echovault)：一个写作工具原型，尝试用自己过去的文字作为参考，辅助起草新内容。
- [Research Topic Copilot](https://github.com/tian415/research-topic-copilot)：用 Dify 搭的科研选题工作流，尝试把比较模糊的想法一步步整理成选题提案。

这些项目目前以个人使用和实验为主，还在修改。具体做到了什么、怎么运行，都写在各自的 README 里。
