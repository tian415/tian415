# Timmy · AIPM

我把自己反复遇到的阅读、笔记和写作问题做成小工具。新闻读到一半，能点回原文；一段讨论改变了原来的判断，能看见笔记改了哪里。这里放的是我用 AI 辅助开发、可以亲手试的作品。

## 给昨天的笔记加上今天的新结论

在 **Knowledge Agent** 的本地演示里，先保存一篇笔记，再导入第二段讨论。打开更新提案，可以逐段对照原对话、自己的手写补充和即将写入的内容，再决定是否保存。[运行三步演示](https://github.com/tian415/knowledge-agent/blob/main/docs/demo.md) · [查看设计取舍](https://github.com/tian415/knowledge-agent/blob/main/docs/architecture.md)

## 阅读和写作

- **个人新闻助手**　打开一期中文简报，挑一条感兴趣的新闻回到原文。想了解简报怎样生成，可以在本地用合成新闻跑一遍网页、邮件预览和阅读反馈。[阅读往期简报](https://news.timmyworks.com/archive.html) · [运行展示版](https://github.com/tian415/personal-news-showcase)
- **EchoVault**　用一个新想法找回自己过去写过的素材，参考已有表达起草一篇新稿，再导出 Markdown。[查看写作原型](https://github.com/tian415/echovault)
