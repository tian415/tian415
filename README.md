# Timmy · AIPM

我做 AI 阅读、知识整理和写作工具。读新闻时，我想随手查到原文。把讨论整理成笔记时，我想看清 AI 改了哪一段。这里放着我用 AI 辅助开发的原型，以及做这些决定的理由。

**第一次来，可以先看 [Knowledge Agent 的笔记审核界面](https://github.com/tian415/knowledge-agent/blob/main/docs/assets/demo-review.png)。** 假设昨天的讨论已经存成笔记，今天又改了主意。你可以打开原对话，核对新结论会改动哪一段，再决定是否保存。[三步本地演示](https://github.com/tian415/knowledge-agent#三步体验)使用合成对话，无需 API Key。

| 项目 | 可以看什么 |
| --- | --- |
| **Knowledge Agent · 知识整理** | 一篇笔记怎样随着多次讨论更新，怎样保留手工补充的内容，以及写错后怎样恢复。[设计与取舍](https://github.com/tian415/knowledge-agent/blob/main/docs/architecture.md) |
| **个人新闻助手 · 新闻阅读** | 打开一份中文简报，顺着链接读原文。想看背后的流程，可以在本地用合成新闻生成网页和邮件预览，再记录阅读反馈。[往期简报](https://news.timmyworks.com/archive.html) · [运行演示](https://github.com/tian415/personal-news-showcase#本地演示) |
| **科研选题副驾 · Dify 工作流** | 学生只有一个模糊想法时，先问清手头的数据和资源，再比较选题方向。公开的 PRD 和工作流可以对照阅读。[读产品设计](https://github.com/tian415/research-topic-copilot/blob/main/prd.md) · [看工作流](https://github.com/tian415/research-topic-copilot/tree/main/workflow) |
| **EchoVault · 辅助写作** | 把过去的文章整理成素材库，区分哪些可以引用、哪些只供风格参考，再从一个新想法起草并导出 Markdown。[看本地原型](https://github.com/tian415/echovault) |
