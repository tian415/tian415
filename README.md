## 我怎样做项目

- 从自己的使用问题出发，先验证最小闭环，再增加功能。
- 借助 AI 开发，保留对需求、取舍和验收的判断；把模拟演示、代码验证和真实效果分开说明。
- 让模型提出建议，让程序检查边界，让使用者决定重要变更。

这些是持续迭代的个人项目，尚不代表生产服务或长期效果已验证。技术实现涉及 Node.js / JavaScript、Next.js / TypeScript 和 Dify，具体使用范围见各仓库。

最近整理：2026 年 10 月。项目问题与改进建议可到对应仓库交流。
